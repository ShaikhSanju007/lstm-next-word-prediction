
# LSTM Next Word Prediction

A next-word prediction application built using Deep Learning, LSTM, TensorFlow, and Streamlit.

## Features
- Predicts the next word from user input
- Uses an LSTM neural network
- Interactive Streamlit web interface

## Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Streamlit

## Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Run the app:

```bash
python -m streamlit run app.py
```

## Project Files
- `app.py` — Streamlit application
- `LSTM Model.h5` — Trained LSTM model
- `Tokenizer for Next Word Prediction.pkl` — Saved tokenizer
- `max len.pkl` — Saved sequence length
